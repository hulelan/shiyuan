# 诗渊 · 古诗古文集

一个古诗古文在线库的原型。每一篇作品都配有 **原文 · 拼音 · 译文 · 注释 · 赏析 · 英译**，并可从 **诗文库 / 主题 / 时间轴 / 地图** 四个角度探索，感受文言文的历史流变。

## 打开方式

- **最简单**：直接双击 `index.html`，用浏览器打开即可。
  （诗文数据以 `<script>` 加载，无需服务器；仅"地图"视图的底图需要联网。）
- **本地服务器**（可选，体验更完整）：
  ```bash
  cd poetry
  python3 -m http.server 8731
  # 浏览器打开 http://127.0.0.1:8731/
  ```

## 目录结构

```
poetry/
```

## 如何添加一首新作品

只需在 `data/poems.js` 的 `window.POEMS` 数组里，按下面的模板追加一条对象。
应用会自动更新诗文库、主题、时间轴与地图 —— 无需改动任何代码。

```js
{
  id: "唯一英文标识",              // 如 "denggao"
  title: "标题",
  author: "作者",                 // 作者不详写 "佚名"
  dynasty: "唐",                  // 须是 DYNASTIES 中的朝代
  dynastyOrder: 6,                // 对应朝代的排序权重
  year: 767,                      // 约略年份，公元前用负数（用于时间轴排序）
  yearLabel: "盛唐 767 年",        // 展示用的年份文字
  form: "七言律诗",               // 体裁 / 格律
  genre: "诗",                    // 诗 / 词 / 曲 / 文 / 赋
  themes: ["登高", "羁旅"],        // 主题标签，可多个（主题视图据此聚合）
  place: { name: "夔州", modern: "今重庆奉节", lat: 31.02, lng: 109.46 }, // 地图坐标
  text: "第一句。\n第二句。",       // 原文，句子间用 \n 换行
  pinyin: "dì yī jù 。\ndì èr jù 。", // 拼音，逐行对应 text（可留空 ""）
  translation: "白话译文……",
  notes: [ { term: "词语", explain: "解释" } ],  // 注释，可多条
  appreciation: "赏析……",
  english: "English translation…",
  englishBy: "编者译"              // 英译出处（可选）
}
```

> ⚠️ 注意：中文文本内部若要引号，请使用全角 “ ” ，避免与 JS 字符串的英文引号冲突。

## 数据管线（已搭好）

现在站点收录 **12 篇精编 + 2954 篇导入 ≈ 2966 篇**，跨 先秦 / 唐 / 宋 / 元 / 清，
含 诗（诗经·楚辞·唐诗）、词（宋词·纳兰）、曲（元曲），以及 **文言文（论语·大学·中庸·孟子）**。
文言文按"章/段"拆条，每条一张卡片。

```
tools/
├── build_corpus.py   从 chinese-poetry 拉原文 → 繁转简 → 生成拼音 → data/corpus.{json,js}
├── enrich_glm.py     用 GLM-4.7（OpenRouter）补 译文/注释/赏析/英译/主题/地点/年份
└── .cache/           下载缓存（gitignore）
```

数据分两层，分别对应两个来源，互不覆盖：

- `data/poems.js` — **手工精编**的 12 篇（`window.POEMS`），六层内容齐全，是质量标杆。
- `data/corpus.js` — **自动导入**的 2088 篇（`window.POEMS_IMPORTED`）。原文来自
  [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（公有领域），拼音自动生成；
  译文/注释/赏析/英译/主题/地点由 GLM 生成后填入，页面会标注"AI 生成·待校订"。

### 1) 重建 / 扩充原文库

```bash
cd tools
../.venv/bin/python build_corpus.py     # 编辑脚本顶部 SOURCES 可增删语料、调整数量
```

### 2) 用 GLM 生成译文/注释/赏析/英译

先把 OpenRouter 密钥放进项目根目录的 `.env`（该文件已 gitignore，**不要提交**）：

```
OPENROUTER_API_KEY=sk-or-你的key
```

然后：

```bash
cd tools
../.venv/bin/python enrich_glm.py --limit 20     # 先试 20 首，看看质量
../.venv/bin/python enrich_glm.py                # 满意后跑全部（可随时中断续跑）
```

- 模型 `z-ai/glm-4.7`，约 **$1.7 / 千首**；脚本每 20 首自动落盘，断了再跑会跳过已完成的。
- 生成完刷新网页即可看到译文、注释、赏析、英译，且地图/时间轴会因补上地点与年份而更丰富。
